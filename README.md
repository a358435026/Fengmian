# 自由对话 · iPhone 持续双语录音翻译

原生 SwiftUI App，最低 iOS 15.0。选择两种语言，点击一次开始，持续录音；双方轮流讲话，逐段展示原文和译文。结束后选择将录音及双语文字保存在本机，或删除临时录音。无需 App Store 上架，不需要自己的服务器。

当前版本 0.2.0。真机编译/测试结果与最终 IPA 以 [验证记录](docs/VERIFICATION.md) 为准，不能把源码完成当作真机识别准确率已提高。

## 主要行为

- 一个开始/结束按钮，识别和翻译期间录音不停止。
- 将相同音频交给所选两个系统语音识别器，结合文本语言证据、最终识别结果和候选差距判断方向。这是双语候选判定，不能等同于经过专业验证的音频语言分类器。
- 证据不足、短词、识别未最终定稿或两个候选接近时，展示“识别待确认”，保留候选，不自动翻译或播报。可继续说话，再核对这些条目。
- 默认停顿 1.3 秒收句，要求原文稳定至少 0.65 秒；收句后等待最终修订，最长 3.5 秒。下一段识别同时开始，不等待上一段翻译。
- 自适应音量阈值、约 0.25 秒音频预缓冲、过响失真提示；每段最长约 28 秒，避免系统单次识别时限。
- 译文按队列请求官方 DeepSeek；近期最多四条已确认上下文用于术语和指代，输出只含译文。保留数字、单位、否定和不确定语气，不猜测修复错误原文。
- 所有条目可修正原文和语言，再翻译；修改期间旧请求不能覆盖新原文。
- 自动播报默认关闭，确保持续识别。开启后，播报时录音继续，但暂停识别，以免把译音再次翻译；期间其他人讲话可能没有文字识别。因此需要双方不断讲话时，应关闭自动播报。
- 结束后可保存：压缩录音 `audio.m4a`、可读双语 `transcript.txt`、结构化 `transcript.json`。从左上角文件夹播放、删除或自行导出；没有自动上传保存的文件。
- 不保留时删除本次临时音频；屏幕文字仍可查看。未选择保存就退出，临时音频下次启动会清理。
- API Key 仅存本机 Keychain，不内置在 IPA 或 GitHub 仓库。

录音持续写入本机临时 CAF 文件，结束保存时转换成 M4A。长录音需要临时储存空间。录音时保持屏幕常亮，避免自动锁屏中断。手动锁屏、退后台、来电或音频设备断开会结束对话，待回到界面后选择保存；本版不支持锁屏后台持续录音。

## 能力与准确率边界

选择列表中有 17 个常用语言配置，但能否识别取决于 iOS 和设备的系统支持。若双语识别不支持、Apple 请求受限或网络断开，可能没有原文或出现待确认；原始录音仍用于本地核对。

两个单语识别器的置信度不是经过跨语种校准的概率。即使判定通过，原文也可能错误；此版提高了收句完整性和不确定性可见性，尚未有真实音频证据证明错误率下降。英语↔法语等同字母语言、短数字、人名、夹杂语言尤其需要测试。双方同时讲话不保证能分离。

DeepSeek 只收到识别后的文字，不接收音频，不能知道原声究竟说了什么。提示词和上下文不能替代语音识别质量。真实客户关键的金额、否定、规格、时间请核对原文与录音。

在线系统识别可能将音频发送给 Apple；选“只使用设备端识别”会检查两种语言的设备端能力，不自动联网兜底。**iOS 15 的文字翻译使用联网 DeepSeek，本版不提供离线翻译包。**

## 安装

通过已有 TrollStore 导入 `releases/ConversationTranslator-iOS15-TrollStore.ipa`。打开“自由对话”，右上角设置填写自己的 DeepSeek 官方 API Key，选择语言并允许麦克风和语音识别权限。

巨魔错误 173 一般涉及 ldid 未安装或签名失败，请检查 TrollStore 设置。普通 iPhone 无法直接安装此未签名 IPA，需要 Xcode 开发签名或其他合法签名路径。

## macOS 构建

```bash
brew install xcodegen
xcodegen generate
open ConversationTranslator.xcodeproj
./scripts/build-ipa.sh
```

Xcode 项目最低 iOS 15，源码仅使用系统框架。GitHub workflow 在 `a358435026/Fengmian` 的独立 `translator-ios-build` 分支执行；主分支不修改。迁移到自己的独立仓库时可修改 workflow 分支条件。

## API 延迟测量

```bash
read -s -p 'DeepSeek API Key: ' DEEPSEEK_API_KEY
export DEEPSEEK_API_KEY
python3 scripts/probe_deepseek.py --source Chinese --target English
unset DEEPSEEK_API_KEY
```

探针无额外依赖，会发送一条翻译请求并产生 API 费用。只测文字 API，不能代表录音结束到听到译音的完整时延。按语言/句长/网络分别测 P50、P95 与失败率，不能用最快一次承诺性能。

更多细节见 [实现与验收重点](docs/PLAN.md)、[真机验收清单](docs/ACCEPTANCE.md)。
