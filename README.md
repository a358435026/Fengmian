# Electric Motorcycle Cover Skill

An AI skill for creating high-fidelity electric motorcycle social-media covers and product posters from real motorcycle photos.

It is designed for Facebook, TikTok, Reels, Shorts and WeChat Channels, with emphasis on preserving the original motorcycle identity, real factory/showroom background, exact product specifications and mobile-friendly commercial layouts.

## What it does

- Preserves the source motorcycle's design, proportions, color and visible hardware.
- Keeps real factory/showroom context instead of automatically replacing the background.
- Uses exact user-supplied motor power, top speed, price and other numeric parameters.
- Adapts visual style to the product color, motorcycle type, environment and platform.
- Supports vertical formats such as 9:16 and 9:12 as well as 4:5 and 1:1.
- Keeps advertising density restrained by default for cleaner social-media covers.
