# iOS 15 巨魔安装

1. 下载 `ConversationTranslator-iOS15-TrollStore.ipa`。
2. 分享到 TrollStore，或在 TrollStore 点 + 选择 IPA 安装。
3. 打开“自由对话”，在右上角设置填入自己的 DeepSeek 官方 API 密钥并保存。
4. 选择两种语言；双方分别点自己的语言按钮说话，停顿后自动翻译和播报。
5. 首次允许麦克风与语音识别。播报时停止录音，防止回声。

iOS 15 的文字翻译需要联网。本版尚不自动判断双方语言。

如 TrollStore 提示错误 173，请检查其设置中 ldid 是否已安装。其他错误请提供错误码。

已通过 Xcode 编译和 7 项自动测试，最低版本 15.0；实体 iOS 15 的安装、麦克风、声音和 API 时延仍需实际验证。
