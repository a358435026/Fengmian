# 安装 v0.4.0 build 9

最低 iOS 15，iPhone arm64。使用已经安装的 TrollStore 导入 `ConversationTranslator-v0.4.0-b9-iOS15.ipa`。同一 Bundle ID 可覆盖升级，勿先卸载以免丢失本地记录。

1. 设置 → 翻译模型，选择官方服务或自定义中转，填地址与密钥。
2. 点击“获取可用模型”，搜索并点选准确 ID。DeepSeek 官方当前返回 `deepseek-flash` 和 `deepseek-v4-pro`。此次建议先选择已试译成功的 `deepseek-v4-pro`，也可点击“恢复该服务的默认配置”。显示名 `DeepSeek-V4.1-Flash` 不等于 API ID，`DeepSeek-Flash` 大小写不正确。
3. 点击“测试连接与翻译”。收到完整英文译文后，点击“保存并启用此配置”。获取列表与测试本身不会覆盖已启用配置。
4. 如果失败，按照模型、权限、余额、限流或超时提示处理；不支持模型列表的中转可手填它提供的准确 ID。
5. 默认浅色界面，设置中可选深色。返回主界面选择双方语言，先验证文字翻译，再开始持续对话。
6. 结束后选择保存或丢弃录音；历史记录可搜索、查看双语详情、播放、导出和删除。

此次 `deepseek-v4-pro` 流式短句试译成功，完整译文约 2.4 秒；Flash 请求仍出现等待。模型列表成功不能保证翻译低延迟。App 设置 60 秒总等待期限并取消超时请求。此期限不是实时对话的性能承诺。安装包编译与自动化检查不能替代实际手机、语音识别与服务商账户测试。

普通未支持 TrollStore 的手机需要额外签名才能安装。
