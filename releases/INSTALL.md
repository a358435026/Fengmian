# 安装 v0.3.0 build 8

最低 iOS 15，iPhone arm64。使用已经安装的 TrollStore 导入 `ConversationTranslator-v0.3.0-b8-iOS15.ipa`，保持同一 Bundle ID 覆盖升级，勿先卸载以免丢失本地记录。

1. 设置 → API / 模型配置，选择服务商，核对地址及模型 ID，填写密钥。
2. 点击“测试连接与翻译”。看到英文译文即完成实际请求；若失败，查看具体错误。
3. 点击“保存并启用此配置”，返回主界面。
4. 选择双方语言，先用文字输入验证，再开始持续对话并允许麦克风/识别权限。
5. 待核对原文会显示试译，可以修正原文和语言后重译。此类试译不自动播报。
6. 结束后选择保存或丢弃录音；历史记录可以搜索、查看双语详情、播放、导出和删除。

本包已通过 18 项核心自动化测试及 iOS 15 arm64 Release 编译，未替代实际手机、麦克风与服务商账户测试。第三方中转需匹配协议；Claude/Gemini 原生接口采用非流式响应。普通未支持 TrollStore 的手机需要额外签名才能安装。
