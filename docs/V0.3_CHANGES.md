# v0.3.0 build 8

依据用户三张参考图采用深蓝背景、蓝紫渐变主按钮、语言胶囊、双语卡片与波形；设置采用分组卡片，历史页支持搜索与双语详情。

修复识别待确认阻塞翻译队列：所有非空识别片段都尝试翻译，不可靠条目明确标为试译，并仍禁止自动播报。自动判断不是音频级语言检测，不保证选择正确；允许核对原文和语言后重译。正常连续对话不需要逐句确认。

API 可配置 HTTPS 地址、模型 ID、密钥和协议。预设 DeepSeek、OpenAI、Claude、Gemini、通义、Kimi、GLM，并支持自定义中转。OpenAI 兼容接口采用流式响应，Anthropic 与 Gemini 使用原生非流式协议。模型默认值可编辑，需以服务商实际可用模型为准。测试按钮对当前草稿发出真实翻译请求，显示译文、耗时及失败状态，测试不会自动保存。密钥按服务商分开存储，旧 DeepSeek 密钥保留。

保持 iOS 15 与本地录音。没有加入账户、云同步、虚假的云端音频识别选项。识别音频可能由 Apple 在线处理；DeepSeek 只负责文字翻译。

验证：GitHub macOS 核心测试包括流式 Unicode、截断、鉴权、第三方地址与模型、Claude/Gemini 原生协议、地址拒绝与本地归档。真实服务商密钥未提供，实际账户权限、地区限制、识别准确率与真机布局需安装后验证。
