# 真机验收（待 iOS 15 用户安装）

自动测试不能代替录音、系统 Speech 权限、双语识别和实际网络验收。

- 同一安装包覆盖旧版，Keychain 中 API Key 仍可读取；新版自动播报默认关闭。
- 中文↔英语、中文↔法语各轮流说 20 句：只按一次开始，换语言不点按钮；原文上方、译文下方，时间顺序正确。
- API 翻译期间继续讲话，下一句没有因翻译停止收音而丢失。
- 测试短词、数字、人名、否定、单位和两个识别候选接近；待确认条目不得自动翻译/播报。
- 修正原文和语言后，旧请求不能覆盖修订后的新结果。
- 对照原始录音检查末尾词、静音间隔、长句分段和预缓冲重复。
- 双 ASR 是否能稳定运行、在线系统请求限制、设备端两种语言支持，必须实测。
- 外放正常音量、轻声、安静/嘈杂、不同距离分别测；不要把过响当识别优化。
- 自动播报开启时暂停识别、录音继续；讲话可能不被转成文字，关闭后恢复持续识别。
- 停止后，最后一段完成识别与翻译，再选择保存/不保存。待确认原文与候选在保存文件中明确标注。
- M4A 可以播放；TXT/JSON 包含所有记录及时间，库中可删除、可导出到“文件”。
- 不保存时临时音频删除；保存失败可重试，不删除已有录音。
- 来电、退后台、蓝牙断开时结束会话；恢复界面能决定是否保存。
- 飞行模式/错误 API Key/限流时录音仍可保存，未完成译文不得当作成功播报。
- 记录识别错误率、方向错误率、待确认比例、句尾丢失率，以及完整端到端 P50/P95；不要仅用 API 时间代表准确率和语音总时延。
