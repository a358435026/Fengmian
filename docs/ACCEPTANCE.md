# 验收清单（尚未执行真机验收）

## 构建与安装

- 使用 iOS 18+ SDK，构建 iOS 15 deployment target；在一台 iOS 15–17 设备启动，确认 Translation 弱链接不影响旧系统。
- macOS 的 GitHub workflow 单元测试通过，Release iphoneos 编译成功。
- 巨魔安装 IPA，确认启动、Speech 授权和 Keychain 保存/重启读取工作正常。
- 普通 iPhone 经 Xcode 签名安装，确认权限和播报。

## 功能与错误

- 两侧各说 20 条真实短句，核对方向、数字、人名和译文，不能只有中文→英语。
- 拒绝麦克风/Speech 权限时明确提示；重新到系统设置授权后能恢复。
- 无 Key、错误 Key、余额不足、429、飞行模式、响应中断、停止翻译，均不将半截译文当成功播报。
- 播报时不会录入自己的声音；停止、退后台、来电、蓝牙断开时关闭当前会话。
- 连续监听默认关闭；打开后只监听当前选中方向，换人点击另一侧。
- 文字输入方向可切换；翻译未完成的条目不可重播。
- 清空记录后无旧任务继续写回；退出应用后无对话持久化。
- 为安静/普通室内/嘈杂、轻声/正常音量分别测收句；RMS 固定阈值需要按结果调整或替换 VAD。

## 离线

- iOS 18+ 当前组合在 prepareTranslation 成功后，飞行模式可翻译文字。
- 单独检查所选语言的 supportsOnDeviceRecognition，开离线识别后断网说话。
- 单独确认已下载目标语言声音，断网可播报。
- 系统不支持的语言组合明确失败；不擅自走 DeepSeek 或在线 Apple ASR。
- 不将希伯来语或任何未实测语种标为“离线支持”。

## 性能

每种方向至少 20 句、不同句长，在手机实际 Wi-Fi/移动网络各测一轮：

| 字段 | 测量边界 |
| --- | --- |
| 识别错误率 | 人工逐句对照；字词/数字/专名分别记录 |
| 收句等待 | 最后一个真实音节到识别提交翻译 |
| API 首字 | 请求开始到第一段 content；App 已显示 |
| 译文完整 | 请求开始到完整译文；App 已显示 |
| 端到端 | 最后一个真实音节到第一段可听懂译音；需外部录像或专项埋点 |
| 离线质量/延迟 | 同一句子同一设备断网对比 |

报告 P50 和 P95，保留失败比例。App 显示的“首字”和“翻译”不能作为完整语音链路的延迟报告。
